# Campus Voice – Independent App

This repository contains everything you need to run the **Campus Voice** app locally or deploy it independently (for example on GitHub Pages or any Node/Express host).

The app no longer depends on Google AI Studio hosting – it is a standalone React + Vite + Express project.

## Run locally

**Prerequisites:** Node.js

1. Install dependencies: `npm install`
2. (Optional, only if you use Gemini) Set `GEMINI_API_KEY` in `.env.local` to your Gemini API key
3. Start the dev server: `npm run dev`
